App de Notas creada para la Materia de Programación Móvil II

La aplicación tiene 2 botones:
. Uno que agrega una nueva nota
. Otro que borra las notas seleccionadas

Las notas cambian a color verde al hacer un touch corto. para mostrar las tareas completadas.

Al mantener el touch quedan seleccionadas para luego borrarlas con el botón.

Código Secreto: se activa al escribir “pan” y agregarlo como una nueva nota. La funcionalidad cambia a enviar un mensaje de alerta.

Tambien se agrego un botón que permite retroceder la pantalla de alerta.
